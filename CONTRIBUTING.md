# Contributing to TreeSeed Agent

Human and agent contributions use the same durable pull-request record. Select the contributor mode and preserve the exact base/head refs, work authority, verification, commits, risk, rollback, and completion summary.

This repository is licensed under Apache-2.0. In accordance with Section 5 of that license, an intentionally submitted contribution is provided under Apache-2.0 without additional terms unless you explicitly state otherwise. The repository does not require a separate contributor-grant checkbox, standing contributor authorization, or approved-committer allowlist.

Do not submit code, documentation, or other material you do not have the right to contribute. Review [LICENSE](LICENSE) before submitting.
